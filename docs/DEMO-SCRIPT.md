Preparation: open the production build, confirm sound level, choose **Expo Demo** (instant text turns on for the demo). It begins with no recorded findings. Keep a separate local production preview ready as a fallback. Times below are rehearsal targets, not a measured claim.

| Time | Action and narration |
|---|---|
| 0–12s | “This is Abyssal Trace, an underwater inspection-survival game. You decide who enters a damaged refuge using actual digital evidence.” |
| 12–25s | Open Nacre’s airlock view. “Nacre claims this is a fresh image from camera C7 at 22:18.” Receive the recorder. |
| 25–45s | Return to Office → Recovery Cradle → Load Nacre’s recorder → Scan recorder. “This scans the actual binary dump, follows PNG chunk boundaries, and verifies checksums.” Record finding. |

| 70–88s | Close device → airlock → More questions → “The archive matches. C7 was disconnected.” Deny → Confirm denial. |
| 88–105s | Show Encounter Review. “The decision combines a claim, a measured file match, and independent station records. A hash does not identify a person.” |
| 105–120s | “The full shift includes four visitors, including an innocent hidden message and a legitimate backup. The same instruments accept your own supported files, locally in the browser.” |

Do not add Signal Scope to this route unless a timed rehearsal leaves room. For Q&A, Open Instruments → Signal Scope → Load encoded PNG sample → Decode RGB signal displays an actual P9LSB1 message. Switch to R to show the honest unsupported-scheme result.

Likely questions:

- **What is real?** Byte-level PNG carving, supported low-bit decoding, runtime SHA-256, local uploads, and exports.
- **What is fictional?** Characters, station records, claims, and ground-truth identities.
- **Does hidden data mean guilt?** No. Vela’s concealed emergency message agrees with the pump alarm. Rook’s duplicated backup supports exactly what Rook claims.
- **Does it use an AI service?** No. Authoring used Codex; running the game uses bundled files and browser APIs.
- **What is unfinished?** Approved final art, supplied sounds, final visual integration, and a measured first-player pacing pass.
